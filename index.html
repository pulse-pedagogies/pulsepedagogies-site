Software for education, built by educators

Pulse Pedagogies, LLC is a software studio in Glendale, California, founded by two career educators. We build web and mobile tools for schools and the people who run them.

  • clearAMS: free Prop 28 Arts and Music in Schools planning and compliance for every California district, ready for AB 2440 site certification.
  • VAPA Pulse: arts curriculum support for visual and performing arts teachers.
  • Signet: professional learning from the first request for a seat to a signed credential anyone can verify, inside the Google Workspace your organization already runs.
